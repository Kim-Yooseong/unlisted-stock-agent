# 📈 비상장 주식투자 도움 에이전트

> 금융인공지능실무 수업 프로젝트
> 일반 개인투자자를 위한 **비상장주식 정보 브리핑 AI 에이전트**

## 프로젝트 소개
비상장주식 시장은 정보가 흩어져 있고, 개인투자자가 기업의 실체·상장 일정·거래 방법·위험 요소를 한눈에 파악하기 어렵습니다.
이 프로젝트는 증권사·회계법인 IPO 리포트, 금융감독원 전자공시(DART) 등 **출처가 확실한 자료만 근거로** 비상장 기업 정보를 요약·브리핑해 주는 AI 에이전트를 만드는 것을 목표로 합니다.

※ 이 서비스는 투자 권유나 매수 추천이 아닌 **객관적 정보 제공**을 목적으로 합니다.

## 주요 기능 (계획)
| 구분 | 기능 | 상태 |
|---|---|---|
| 필수 | AI 대화 에이전트 (종목 요약 → 리포트 핵심 → 거래 플랫폼 → 주의사항 순서로 답변) | ⏳ 예정 |
| 필수 | 주목 종목 카드 10~15개 (섹터, 주요 투자 VC, IPO 단계, 통일주권·거래 플랫폼, 리스크) | ⏳ 예정 |
| 필수 | IPO 진행 일정 표 (예비심사 청구 ~ 청약) | ⏳ 예정 |
| 필수 | 모든 답변에 출처 표기 및 투자 책임 고지(면책 문구) | ⏳ 예정 |
| 선택 | 상장 동종업계(Peer) 비교 차트 | ⏳ 예정 |
| 선택 | 장외 종목 팩트체크 (DART 등록 여부 등) | ⏳ 예정 |
| 선택 | 장외주식 세금 참고 계산기 | ⏳ 예정 |

## 사용 기술 (모두 무료)
- **AI 모델**: Google Gemini API (무료 등급)
- **웹 화면**: Python + Streamlit
- **배포**: Streamlit Community Cloud
- **데이터**: 금융감독원 DART OpenAPI, 증권사·회계법인 IPO 리포트, 직접 정리한 종목 데이터(CSV)
- **AI 기법**: RAG(검색증강생성), 프롬프트 엔지니어링

## ⚠️ 면책 고지
본 서비스가 제공하는 정보는 투자 판단을 위한 참고 자료이며, 특정 종목의 매수·매도를 권유하지 않습니다. 비상장주식은 원금 손실 위험이 크며, 투자에 대한 책임은 투자자 본인에게 있습니다.
